# Omnex

A free, easy game server manager for Windows. Install, run, and manage
dedicated game servers from one clean desktop app.

**Supported games:** Minecraft (Vanilla / Paper / Fabric), CS2, Valheim,
Rust, Satisfactory, Project Zomboid, Ark: Survival, V Rising, Terraria,
7 Days to Die, Palworld, Enshrouded.

## Features

- One-click install, start, stop, restart, update
- Live server console with search
- Full config editor with every game setting exposed
- Automatic and scheduled backups with retention
- Crash detection and optional auto-restart
- Modrinth mod browser for Minecraft (Paper/Fabric)
- Windows Firewall helper — one-click port rules
- System tray + minimize-to-tray
- Adjustable app-wide text scale
- Live log tailing for games that write to files (Palworld, Ark, etc.)

## Installation

1. Download the latest `Omnex Setup 1.x.x.exe` from the releases page.
2. Run the installer (requires administrator privileges for firewall
   management and per-machine install).
3. Launch Omnex from the Start menu or desktop shortcut.

## Requirements

- Windows 10 or 11 (64-bit)
- ~200 MB free disk space for Omnex itself, plus whatever each game server needs
- Administrator access to elevate installations and manage firewall rules

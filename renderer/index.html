💬 Discord
Send events to Discord
Master switch — must be ON for anything below to post. (The 🔔 Test button works even while this is off.)
Webhook URL (default channel)
In Discord: Channel → Edit → Integrations → Webhooks → New Webhook → Copy URL. Running multiple servers? Give each its own channel from that server's Network panel — this is the fallback.
Forward in-game chat
Post players' chat messages to Discord — a live window into the server
Forward deaths & advancements
Post the fun moments — deaths and earned advancements — to Discord
🤖 Bot control (run /start /stop /restart /backup /status from Discord)
Needs a Discord bot (not just a webhook). Create one at discord.com/developers → New Application → Bot → Reset & Copy Token. A command targets the server linked to the channel it's run in (via that server's webhook). Only the user IDs listed below may run commands.
Enable bot control
These users can run commands on every server. For access to just one server, use that server's Network panel. In Discord: User Settings → Advanced → Developer Mode ON, then right-click a person → Copy User ID. (/status is open to everyone.)
Gates the destructive Discord commands (on top of admin status). /create requires it only when set; /deleteserver always requires it — remote delete stays disabled until you set one. Lives only here in Omnex, never shown in Discord.
